# Ruta con Discovery

1. PO deposita artefactos reales en `Product-Definition/` (reemplaza stubs).
2. `ENTRY_MODE.md` = `with-discovery`.
3. Abrir Issue **Discovery Handoff** y pegar `HANDOFF_PROMPT.md`.
4. Dev ejecuta Gate 0.
5. Review Sync (~30 min) si hay brechas.
6. Sign-off: `.aidlc/aidlc-state.md` → `gate_status: approved`.
7. Encender orquestador con el Handoff del IDE correspondiente.

Guia de equipo: `docs/guides/gobierno-iadlc-intelix.md`.
