# Instructivo PO → Dev

1. Cierra Discovery (o entrega los markdown de `Product-Definition/`).
2. Sube la carpeta al repo o adjunta el ZIP al Issue **Discovery Handoff**.
3. Pega `HANDOFF_PROMPT.md` en el Issue.
4. El desarrollador corre Gate 0 y agenda 30 minutos si hay brechas.
5. Durante Inception/Construction, los cambios de alcance se registran con
   `intelix-inception-iterations` (fechas + HH + impacto en develop).

No hace falta operar la consola del orquestador: el Dev enciende AI-DLC con ese archivo.
