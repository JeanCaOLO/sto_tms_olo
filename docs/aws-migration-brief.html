02 — ALCANCE

Qué corre hoy en AWS — y qué no todavía

La migración cubrió la base de datos y su capa de acceso. El resto del stack — hosting del frontend, VPN permanente, y un segundo proyecto separado — quedó fuera de este alcance.

En AWS ahora
  • Base de datos completa del TMS — esquema y datos reales de las 28 tablas/vistas de producción.
  • Autenticación de los usuarios — login, sesiones y contraseñas propias, sin Supabase Auth.
  • API que sirve toda la app — pedidos, rutas, transportistas, vehículos, conductores, clientes, tiendas, contratos, liquidaciones y tracking.
  • Desarrollo y administración de la BD — migraciones y esquema gestionados directamente en AWS.
Fuera de alcance / pendiente
  • Acceso permanente a la base — hoy depende de un túnel manual (SSM); falta VPN o mover la API dentro de la VPC.
  • Proyecto "Liquidador" — prototipo separado, sigue en su propio Supabase, no migrado.
  • Hosting del frontend — el sitio Vite/React no se movió a AWS en esta fase.
  • Scoping por organización — las políticas RLS de algunas tablas no se reimplementaron aún en la API.
